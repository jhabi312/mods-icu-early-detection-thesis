# Predictive Clinical Protocol for Early MODS Detection

**M.Sc. Thesis — University of Ibadan, 2024**  
**Author: Adenikinju Adetunji Emmanuel, RN, RCCN**

---

## Overview

This repository contains the analytical work underpinning my M.Sc. thesis:  
*Development of a Predictive Clinical Protocol for Early Identification of
Multi-Organ Dysfunction Syndrome (MODS) in Post-Operative ICU Patients.*

The protocol detects sub-clinical deterioration up to **6 hours ahead** of
standard electronic alert benchmarks using time-series physiological analysis
of ICU hemodynamic data.

---

## Key Findings

- Predictive framework achieved statistically significant early detection of MODS onset
- Sub-clinical deterioration identified **6 hours ahead** of existing ICU alert benchmarks
- Variables analyzed: MAP trends, lactic acid levels, heart rate variability, fluid balance
- Methods: Logistic regression (SPSS), time-series analysis, Python (pandas, matplotlib), Tableau
